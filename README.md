# apitory-site

Static site for https://apitory.com — served by Cloudflare Pages from this repository (framework: None, build command: none, output: /). Push to `main` auto-deploys in about a minute.

Pages: `index.html` (catalogue of 7 live Actors), `actors/*.html` (one detail page per Actor), `style.css`, `sitemap.xml`, `robots.txt`.

Regenerate from `~/workspace/venture/apitory-site-tools/build_site.py` + `actors.json` — do not hand-edit the HTML.
