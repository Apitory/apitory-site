How it works

  1. Pick an Actor and paste the quickstart input.
  2. Run it on Apify — via the console, the API, or Make / n8n / Zapier.
  3. Read the structured dataset when the run finishes. You pay per delivered result.

Our pricing rule

Pay per use, with the charge tied to a delivered record. Where an Actor charges a premium — for example a Maps lead — it is charged only when the record actually carries a usable public contact. Empty and status records are not premium-charged.
